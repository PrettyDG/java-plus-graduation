# ExploreWithMe

**Микросервисная афиша событий**  
Приложение позволяет пользователям делиться информацией об интересных мероприятиях, публиковать события, оставлять комментарии, ставить оценки, создавать подборки и находить компанию для совместного посещения.

Дипломный проект курса «Java-разработчик плюс» Яндекс Практикума.

## Описание проекта

ExploreWithMe — backend-приложение в микросервисной архитектуре для организации и поиска событий.

Основные возможности:
- Публикация и модерация событий
- Категории событий
- Подборки (компилации) событий
- Комментарии и оценки
- Запросы на участие в приватных событиях
- Сбор и хранение статистики просмотров и действий пользователей

Проект демонстрирует навыки работы с высоконагруженными системами: разделение на сервисы, асинхронное взаимодействие через Kafka, контейнеризация и централизованная конфигурация.

## Технологический стек

- **Язык**: Java 
- **Фреймворк**: Spring Boot
- **Модули Spring**: Web, Data JPA, Security
- **ORM**: Hibernate
- **База данных**: PostgreSQL
- **Сообщения**: Apache Kafka
- **Сборка**: Maven
- **Контейнеризация**: Docker, Docker Compose
- **Сервис-дискавери**: Eureka (Discovery Server)
- **Конфигурация**: Spring Cloud Config
- **Тестирование**: JUnit 5, Mockito
- **Другое**: Lombok, QueryDSL (в некоторых сервисах)

## Архитектура

Приложение разделено на микросервисы:

- **ewm-main-service** (включает Category, Compilation, Event, Request, User, Comments Services)
- **stats-service** — отдельный сервис статистики (сбор hits через `/hit`, получение статистики через `/stats`)

Вспомогательные сервисы:
- **discovery-server** — Eureka для регистрации сервисов
- **config-server** — централизованная конфигурация

## Системные требования

- Docker и Docker Compose (рекомендуется последняя версия)
- Минимум 4 ГБ оперативной памяти (для запуска всех контейнеров)
- Java 11+ и Maven (если запуск без Docker)

## Инструкция по запуску

### Вариант 1: С помощью Docker Compose (рекомендуется)
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/PrettyDG/java-plus-graduation.git
   cd java-plus-graduation

2. Запустите все сервисы: 
  ```bash 
  docker-compose up -d
  ```

Приложение будет доступно:

- Main Service: http://localhost:8080
- Stats Service: http://localhost:9090

### Вариант 2: Локальный запуск без Docker

1. Запустите discovery-server
2. Запустите config-server
3. Запустите stats-service (создайте БД stats)
4. Запустите ewm-main-service (создайте БД ewm)

Порядок запуска вспомогательных сервисов важен — остальные можно запускать в любом порядке.
